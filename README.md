# BPSC PCS Prep — Bihar Public Service Commission, One Place

Everything you need to crack the **BPSC Combined Competitive Examination (CCE)** in one attempt:
syllabus, Bihar-focused notes, rapid-fire GK, booklist, previous-year-question strategy, and a
12-month study plan — all in one repo, all original summaries, free forever (CC BY 4.0).

> **Exam pattern below reflects the 71st CCE notification** (the latest verified pattern as of
> September 2026). BPSC changed the mains pattern between the 70th and 71st CCE, so **always
> verify against the latest official notification** at the BPSC website before you plan.

## The exam in 60 seconds (71st CCE pattern)

| Stage | What | Marks | Time | Counts in merit? |
|---|---|---|---|---|
| **Prelims** | 1 paper: General Studies, 150 MCQs | 150 | 2 hrs | No — screening only |
| **Mains** | Hindi (qualifying) + GS-I + GS-II + Optional + Essay | 1050 (merit) + 100 (qualifying) | 3 hrs each | Yes (1050) |
| **Interview** | Personality test | 120 | ~20–30 min | Yes |
| **Final merit** | Mains (1050) + Interview (120) | **1170** | | |

- **Negative marking:** ⅓ mark per wrong answer in Prelims. No negative marking in Mains.
- **Hindi qualifying:** 100 marks, need 30% (30 marks) to pass; marks not counted in merit.
- **Eligibility:** any graduation; age 21–37 (General), relaxations for reserved categories.
- **Medium:** Hindi or English — both are fully accepted, including in the interview.
