BPSC PCS Prep — Bihar Public Service Commission, One Place

Everything you need to crack the BPSC Combined Competitive Examination (CCE) in one attempt: syllabus, Bihar-focused notes, rapid-fire GK, booklist, previous-year-question strategy, and a 12-month study plan — all in one repo, all original summaries, free forever (CC BY 4.0).

Exam pattern below reflects the 71st CCE notification (the latest verified pattern as of September 2026). BPSC changed the mains pattern between the 70th and 71st CCE, so always verify against the latest official notification at the BPSC website before you plan.

The exam in 60 seconds (71st CCE pattern)

StageWhatMarksTimeCounts in merit?
Prelims1 paper: General Studies, 150 MCQs1502 hrsNo — screening only
MainsHindi (qualifying) + GS-I + GS-II + Optional + Essay1050 (merit) + 100 (qualifying)3 hrs eachYes (1050)
InterviewPersonality test120~20–30 minYes
Final meritMains (1050) + Interview (120)1170
  • Negative marking: ⅓ mark per wrong answer in Prelims. No negative marking in Mains.
  • Hindi qualifying: 100 marks, need 30% (30 marks) to pass; marks not counted in merit.
  • Eligibility: any graduation; age 21–37 (General), relaxations for reserved categories.
  • Medium: Hindi or English — both are fully accepted, including in the interview.

Website

The public site (https://niteshlhsnda-droid.github.io/bpsc-pcs-prep/) is generated from the Markdown sources above — GitHub Pages only serves static files, so a small Python generator does the rendering:

python3 sitegen/build.py            # regenerate the HTML into the repo root
python3 sitegen/build.py --check    # verify two consecutive builds are byte-identical
python3 sitegen/publish.py          # publish everything to GitHub via the API

build.py uses only the Python standard library (a small built-in Markdown converter). pyq-analysis/index.html is copied through byte-for-byte. See [sitegen/README.md](sitegen/README.md) for the page map and conventions.
